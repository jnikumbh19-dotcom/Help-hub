# Help Hub
**Project purpose:** A location-based emergency assistance platform for instant medical, breakdown, police, and specialized help.
**Target users:** Citizens, Business Owners (Service Providers), and Platform Admins.
**Core modules:** Authentication, User Profiles, Service Providers Registry, Emergency Requests, Complaints/Grievances, Admin Dashboard, Business Panel.
**Technology stack:**
- Frontend: React, Vite, Tailwind CSS, TypeScript
- Backend: Node.js, Express.js (To be built)
- Database: MongoDB
**Backend architecture:** RESTful API, Controller-Service-Repository pattern.
**Authentication strategy:** JWT based authentication with Role Based Access Control (RBAC).
**Authorization strategy:** Roles: `user`, `business`, `admin`.
**Current implementation status:** Frontend is fully built using mock data. Backend needs to be built from scratch to replace mock data.
**Current development phase:** Backend Development (Initial).
**Important constraints:** Must align completely with the existing React frontend data models and state management.
